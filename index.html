Principle

How I work

Build tools that actually matter.

practical over perfect. ship, learn, improve.

01 / ship

Put it in front of real use

A working version beats a perfect plan. Release early, keep the first version small.

02 / learn

Watch what actually happens

Notice what breaks, what is slow and what gets ignored. Real use is the best spec.

03 / improve

Fix the real problem

Make the next version simpler and sturdier, not bigger. Then go around again.
